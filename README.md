# TIPSTAT

Osobná analytická appka na štatistiky zápasov (futbal, hokej NHL).

- Appka: priečinok `docs/` (GitHub Pages)
- Dáta: `pipeline/` – spúšťa ich automaticky GitHub Actions 4× denne (`.github/workflows/update.yml`)
- Zdroje: football-data.co.uk (futbal), api-web.nhle.com (NHL) – bezplatné verejné dáta

Ručná aktualizácia: záložka **Actions → Aktualizacia dat → Run workflow**.
